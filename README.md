# Beam Designer

Beam Designer is a Python desktop app for checking simply supported beams and cantilevers. It calculates reactions, shear, moment, deflection, bending and deflection checks, section recommendations, and exports CSV results or a PDF calculation sheet.

## Install

No third-party packages are required. The app uses Python's standard library and Tkinter.

## Start

From the project folder in Command Prompt:

```bat
.venv\Scripts\activate.bat
python beam_designer.py
```
